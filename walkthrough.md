# LINE Sharing, Safety & Family Walkthrough Guide

This guide explains how to safely send the **Granddaughters Learning Widget** to your girlfriend via LINE, how she can share it with her daughter, and how to pin it directly to the child's phone screen like a real app.

---

## 1. Why a Web Link is Best for LINE (vs. Sending a File)

| Method | How it Works in LINE | When You Update a Sound File |
| :--- | :--- | :--- |
| **Option A: Web Link (Recommended)** | Send a single link. They tap once, and it opens instantly in Safari/Chrome. | **Instant auto-refresh.** You update the link on the web, and next time they tap it, the new sound plays automatically. No resending needed. |
| **Option B: Send HTML File** | Send `index.html` as a file attachment. | **Manual resend.** You must send the file again to the grandmother, who must forward it to the daughter, who must re-save it on the kid's phone. |

> [!TIP]
> LINE's built-in file viewer can sometimes block web audio or touch gestures on raw `.html` files. A **clean HTTPS web link** works flawlessly on every iPhone and Android device.

---

## 2. Security & Tamper-Proofing (Zero Risk)

1. **Nobody Can Edit or Break the Code:**
   * Web apps run in a secure, sandboxed browser environment.
   * Neither the grandmother, the mother, nor the child can accidentally edit, delete, or change the code. It is 100% read-only.
2. **Safe for Kids:**
   * No user accounts, no passwords, no ads, no trackers, and no external cookies.
   * Star points are saved strictly to the phone's local storage (`localStorage`).
3. **Offline Ready:**
   * Once loaded, all sounds and vector drawings are embedded inside the app. It does not stream heavy data over cellular networks.

## 4. How to Pin to the Phone Screen ("Add to Home Screen")

No app store download needed. It installs in 5 seconds directly from the browser:

### On iPhone (Apple Safari):
1. Open the link in **Safari**.
2. Tap the **Share button** at the bottom (the square with an arrow pointing up ⬆️).
3. Scroll down and tap **"Add to Home Screen"** (`เพิ่มไปยังหน้าจอโฮม`).
4. Tap **Add** in the top right corner. An app icon will appear right on the home screen!

### On Android (Google Chrome):
1. Open the link in **Chrome**.
2. Tap the **Three Dots menu** in the top right (⋮).
3. Tap **"Add to Home screen"** (`เพิ่มลงในหน้าจอหลัก`).
4. Tap **Install** or **Add**.
